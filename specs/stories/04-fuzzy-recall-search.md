# Story 04 — Поиск по смутному воспоминанию

## Контекст

Помню, что когда-то решали проблему с retry для API-запросов. Не помню — в
`HttpClient` или в `ApiGateway`, какие файлы трогали, был ли это backoff или
jitter.

## Сценарий

Спрашиваю Клода: «у нас была работа по retry для HTTP-вызовов, найди».

Точных якорей нет, а точные слова я не помню — скилл идёт текстовым путём:
`search(query="retry http backoff")`. Термы соединяются OR по умолчанию,
запрос проходит через BM25 по `summary` и телу заметок.
Возвращаются три заметки, верхняя — явно про retry.

Узнаю её по `summary`, прошу развернуть. `get_notes` отдаёт тело: конкретные
файлы (`src/http/RetryPolicy.ts`, `src/http/HttpClient.ts`), решение про
экспоненциальный backoff с jitter и подводный камень — idempotency-ключи для
POST-запросов.

## Результат

Вместо `grep` по кодовой базе и чтения нескольких файлов — суть за два шага.
Клод сам перебрал пару переформулировок запроса, мне не пришлось вспоминать
точные термины.
