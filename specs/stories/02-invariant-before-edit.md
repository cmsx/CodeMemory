# Story 02 — Инвариант не даёт повторить устаревший паттерн

## Контекст

Дорабатываю заказы. Прошу Клода добавить в `OrderService` метод отмены заказа.

## Сценарий

Перед правкой файла скилл срабатывает на триггер «правка файла» →
`search(anchors=["file:app/Services/OrderService.php"])`.

Среди выдачи — заметка с якорем веса `critical` на этот файл: «все статусные
переходы заказа идут только через `DocumentStatusService`; прямые присваивания
`$order->status = …` запрещены — ломают аудит». Благодаря весу `critical` она
попадает в выдачу гарантированно, а не конкурирует за место в лимите.

Клод пишет метод, вызывая `DocumentStatusService` вместо прямого присваивания,
и в ответе ссылается на заметку с этим инвариантом.

## Результат

Инвариант соблюдён автоматически. Без памяти Клод увидел бы в файле оба паттерна
(текущий и устаревший) и мог бы повторить устаревший. Я вижу, на основании чего
принято решение.
